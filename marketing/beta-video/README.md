# Beta invite video

31-second vertical video (1080×1920, MP4) inviting players to the STACK5 beta, built from the real site's look and the player-guide screenshots.

- Edit the text in `video.html` (scenes `s1`–`s8`; timings in `SCENES`).
- Preview frames: `node render.mjs still --preview 2,9,30` (PNG stills).
- Render: `npm install ffmpeg-static` once in this folder, then `node render.mjs out.mp4`. Needs Google Chrome.

Not part of the website; nothing here is deployed.

# Concept: "We don't want eggs. We want a cheater-free game."

A standalone landing-page concept built around the slogan, a reply to the CS2 update where players drop, hatch and feed eggs while the community is still asking for fewer cheaters. Open `index.html` in a browser. It is not part of the site and nothing here is deployed.

- **Palette:** near-black ink, eggshell cream, hazard/yolk yellow (`#ffc53d`, also the caution tape), red for strikes and stamps. Replaces the site's green.
- **Type:** Anton for headlines, Inter for text, JetBrains Mono for labels (Google Fonts here; self-host before using on the live site).
- **Sections:** caution-tape marquee, hero with the slogan and a cracked egg in a scope, "Their update / our update" (Drop, Hatch, Feed becomes Drop the cheaters, Match, Rate), patch notes + Trust Score card, closing "Leave the eggs. Bring four friends."
- All artwork is original SVG/CSS. No Valve or CS2 logos or game art.
- Facts in the copy match the live rules (2+ year Steam account, 500+ h CS2, no recent bans, captains report scores, admin disputes). The player card is fictional.
